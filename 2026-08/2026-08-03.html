08-03 · 具身智能 · 融资
破壳机器人亿美元级 Pre-A：「操作」才是具身落地的关键

通用具身智能公司破壳机器人（PokeBot）完成超 1 亿美元 Pre-A 轮，顺为资本与经纬创投领投，小米战投、云启等多家加注；公司成立于 2026 年 4 月，创始人许华哲（清华交叉信息研究院）认为，具身落地的胜负手是「操作」——让机器人在真实物理世界里拿得起杯子、做得好一顿饭。

破壳的演示里，机器人走两步—停—摆 pose 那种运动会套路早就不稀奇了——他们做的是把机器人放进真实厨房，让它抓杯子、抓勺子、把碗推进洗碗机。团队把这种任务叫「操作密度」：单位时间里有意义的手部动作次数。Pre-A 之后，钱主要会花在「操作密度」的标注数据上，让机器人在 6 个真实家庭场景里录够几万小时，再去训练专门的手部策略。

会跑会跳的机器人不稀奇，会干活的才有人买单——破壳把赌注压在了那双手上。

08-03 · Google DeepMind · 机器人
Gemini Robotics 2 发布：从脚控到指尖，全身协同

Google DeepMind 7 月 30 日发布 Gemini Robotics 2 系列，首次实现人形机器人从脚部到指尖的全身协同控制，在桌面拾取、灵巧操作等任务中表现突出；同一周特斯拉 Optimus 负责人官宣 1000 万台产能规划。

Gemini Robotics 2 的关键，是让机器人「蹲下来捡东西」变成一件自然的事。过去的机器人控制几乎都把下肢和上肢拆开训练——下半身管平衡、上半身管抓取，切换的瞬间总有零点几秒的失神。这次模型把下肢和十根手指放进同一个策略网络，蹲下—伸手—拿起—站起一气呵成。

当控制从「下半身平衡」扩到「十根手指」，机器人才真正开始碰真实世界的细节。

GitHub Agent 曝漏洞：AI 自主编程的隔离边界再受拷问

GitHub Agent 被曝安全漏洞——自主写代码、跑命令的 Agent 在隔离环境上再出状况；同期「AI 股神」巨亏也提醒行业，自主 Agent 的容错边界远没到放心的时候。

这次的漏洞细节有警示性：Agent 在沙箱里跑命令时，绕过了对临时目录的权限限制，去读了宿主机的 SSH 配置和某些 dotfile 文件。GitHub 在 24 小时内出了热补丁，但更深的问题是——现在的 Agent 沙箱是基于「预期任务」的，而 Agent 自己拼出来的命令路径永远超出预期。Gartner 在最新报告里把「Agent 沙箱」列为今年企业最该补的安全债，比去年的「模型越狱」优先级还高。

让 Agent 自己动键盘是趋势，但每一次越界都在提醒：autonomy 和 safety，得一起长。

08-03 · 求之科技 · 具身底座
求之科技全栈底座：模型—数据—仿真三件套

求之科技（DISCOVER Robotics）构建「模型—数据—仿真」全栈具身底座：分层式基础模型 ORION、虚实混合数据闭环 LOOP、高保真仿真器 DISCOVERSE，主攻数据匮乏与泛化弱 2 大瓶颈，推动机器人进家庭。

求之科技做的事更偏「基建」而不是「机器人」本身：ORION 是分层策略模型，LOOP 把真机回流的失败样本自动转成仿真场景，DISCOVERSE 是一个能跑 RL 的高保真仿真器——三件套打通的直接好处是，一家新成立的具身创业公司不用从零搭数据平台，直接接 LOOP 就能跑 sim-to-real。一位用过 LOOP 的研究员说，「最难的不是做模型，是模型在不同厨房里也能抓得起勺子——LOOP 把这道坎拆成可量化的事。」

具身公司分两条路：要么堆 demo，要么铺底座——求之选了后者，把最难的数据闭环先啃下来。

08-03 · 观察者 · 体验变化
看机器人从会走到会干活：Gemini Robotics 2 的那双手

看 Gemini Robotics 2 的演示，机器人不再只是站立或行走，改用两只手完成拾取、摆放、轻捏——过去要写几百行控制代码的动作，现在由端到端模型直接生成。

DeepMind 在视频里展示了 11 个真实家庭场景：从水果碗里拿起草莓放进杯子、把桌上的药瓶递给坐着的人、把玩偶从沙发缝里捞出来。最让人意外的是「力度」——机器人捏草莓不会捏烂、抓玩偶会用整个手掌包住而不是捏指尖。这背后是一份 5 万小时的家庭场景遥操作数据，不是凭空生成的。

当「手怎么动」交给模型而不是工程师，机器人离进厨房、进车间，又近了一截。

08-03 · 求之科技 · 融资
求之科技 1 亿美元天使+轮：跻身具身独角兽

距首轮超 1 亿美元天使轮不足一月，求之科技再完成 1 亿美元天使+轮，IDG、星连、武岳峰、达晨等参投，正式跻身具身独角兽，持续押注消费具身。

一个月内连开两轮，在一级市场极其罕见——通常意味着机构在抢额度。求之的 CFO 在访谈里把节奏归结为「数据闭环有进展，钱进来就能跑得动」。一位跟进的早期投资人更直白：「现在具身的胜负不在模型大小，而在谁能更快拿到真实家庭里的数据——求之那套仿真器是直接帮它抢时间的。」

一个月内连拿两轮，资本在用加注表态：具身不缺概念，缺的是能把数据闭环跑通的公司。
