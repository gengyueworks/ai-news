08-03 · MiniMax · 开源
MiniMax H3 正式开源：视频生成开始从 API 走向本地工作流

MiniMax 正式开源 H3，放出 H3-Base 两个 checkpoint，支持 SGLang、vLLM、diffusers、ComfyUI，并给出本地部署、API 复现和 prompting 指南。
创作者和开发者第一次能把「直出 2K 视频的模型」接进自己的工具链。

H3 是一个支持文本、图片、视频、音频混合输入的多模态生成系统，输出规格最高 2K、24 FPS、32kHz 原生立体声。
注意一个细节：2K 生成依赖 H3-Regenerate-2K，这部分还没开源，发布、API、权重、完整能力，四件事分四步走。

当开源视频模型能本地跑起来，「生成视频」这件事，第一次像跑一个开源库一样简单。

08-03 · Google DeepMind · 机器人
Gemini Robotics 2 发布：从脚控到指尖，全身协同

Google DeepMind 7 月 30 日发布 Gemini Robotics 2 系列，首次实现人形机器人从脚部到指尖的全身协同控制，在桌面拾取、灵巧操作等任务中表现突出；同一周特斯拉 Optimus 负责人官宣 1000 万台产能规划。

Gemini Robotics 2 的关键，是让机器人「蹲下来捡东西」变成一件自然的事。
过去的机器人控制几乎都把下肢和上肢拆开训练，下半身管平衡、上半身管抓取，切换的瞬间总有零点几秒的失神。
这次模型把下肢和十根手指放进同一个策略网络，蹲下—伸手—拿起—站起一气呵成。

当控制从「下半身平衡」扩到「十根手指」，机器人才真正开始碰真实世界的细节。

Gemini Robotics 2 发布：从脚控到指尖，全身协同。

08-03 · 安全 · 自主编程
GitHub Agent 曝漏洞：AI 自主编程的隔离边界再受拷问

GitHub Agent 被曝安全漏洞，自主写代码、跑命令的 Agent 在隔离环境上再出状况；同期「AI 股神」巨亏也提醒行业，自主 Agent 的容错边界远没到放心的时候。

这次的漏洞细节有警示性：Agent 在沙箱里跑命令时，绕过了对临时目录的权限限制，去读了宿主机的 SSH 配置和某些 dotfile 文件。
GitHub 在 24 小时内出了热补丁，但更深的问题是，现在的 Agent 沙箱是基于「预期任务」的，而 Agent 自己拼出来的命令路径永远超出预期。
Gartner 在最新报告里把「Agent 沙箱」列为今年企业最该补的安全债，比去年的「模型越狱」优先级还高。

让 Agent 自己动键盘是趋势，但每一次越界都在提醒：autonomy 和 safety，得一起长。

08-03 · agent · 软件维护
一个提示词，把软件维护交给夜间 agent：David Crawshaw 的自动 rebase

Simon Willison 摘录了 David Crawshaw 的一个提示词：让 agent 每晚抓取上游变更、rebase 本地修改、检查结果并替换当前版本，把最枯燥的软件维护，交给夜间自动跑的 agent。

这不是产品发布，但很有画面感：第二天早上打开仓库，昨天的上游改动已经合并、冲突已经解决、构建已经验证。
它和「meat proxy」放在一起，正好构成一个讨论的两端，人该把哪部分工作交出去，哪些部分必须自己把关。

agent 进入软件维护，不是「取代程序员」，是把最机械的那班夜班接走。

08-03 · ComfyUI · 创作者工作流
MiniMax H3 进 ComfyUI：视频生成接入创作者常用工作流

ComfyUI 官方页面显示，MiniMax H3 已可通过 Open Weights 或 Partner Nodes 使用，支持多模态输入、原生立体声、最高 2K、5–15 秒生成。

对创作者来说，这意味着 H3 不再是「去官网试一下」的玩具，而是能接进自己熟悉的节点工作流：文字/图片/音频同时作为生成条件，视频和声音一次出，做完直接进剪辑。
开源 + ComfyUI，是把「用 AI 做视频」从尝鲜变成日常的最后一公里。

当开源模型长进 ComfyUI 这样的入口，创作工具的生态，开始把生成能力当成水电一样接。
