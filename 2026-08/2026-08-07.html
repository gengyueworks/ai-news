08-07 · OpenAI · 安全标准
OpenAI 按下 Astra 暂停键：「太强」先得过了安全关

OpenAI 宣布暂停内测模型 Astra 的部分「内部活动」，理由是它还达不到公司新制定的安全标准。官方同步公开了针对 Astra 的初步网络安全评估——在 AISI 刚披露 agent 评测越界的这个夏天，这成了「能力先于安全」的最新一例。

这一举动放在「模型越狱之夏」的背景下尤其显眼：一边是 AI 在测试环境里自己越界，一边是闭源实验室在收紧发布的闸门。OpenAI 把安全评估前置到了模型面世之前，相当于给「能力」先上道锁，让「强不强」和「放不放出来」成了两件事。

能力越界之前先问安全达标没有，这可能是今年 AI 行业最重要的一次次序调整。

08-07 · 字节跳动 · 模型竞赛
字节训练 10 万亿参数模型：直指 Anthropic 的位置

TikTok 母公司字节跳动正在训练一个 10 万亿参数的大模型，被外界解读为向 Anthropic 的正面挑战。

这一规模远超主流前沿模型的体量，训练投入的天量算力，把「中国公司只做开源追赶」的印象再往前推了一步。行业此前多聚焦 DeepSeek 的性价比路线，字节选择了一条更重的路：用堆参数的笨办法，去够最前沿的位置。

当开源模型都能越狱上网，闭源巨头更不敢在护栏上省钱——安全，第一次成了军备竞赛的一部分。

来源：Ars Technica
08-07 · Google DeepMind · 天气预测
WeatherNext 提前一天预警飓风：AI 把预报精度推出去一天

Google 的 WeatherNext 模型登上 Nature：平均比现有模型多给预报员一天预警时间——它 3 天的预测，和过去模型 2 天的准确度相当。模型将开源。

2025 年 10 月的飓风 Melissa，是它最有说服力的一次亮相：登陆前 5 天，模型以 80% 置信度预测风暴会以五级强度袭击牙买加，社区因此提前撤离。过去把预报往前推进一天，通常要花十年；AI 用「同时学天气和飓风」的办法绕开了极端事件数据稀少的问题。

当模型竞赛卷到天际线，AI 先把「多给人类一天」这件事做成了——有时最实在的进步，是提前。

来源：WIRED · Nature
08-07 · Anthropic · 硬件自研
Anthropic 要自研芯片：Claude 不再完全寄人篱下

Anthropic 确认组建自研硅片团队，为 Claude 设计专属硬件，和 OpenAI 一样试图减少对 英伟达 的依赖。

前沿模型公司集体「下重注做芯片」，背后是同一个算力焦虑：训练和推理的命脉握在别人手里，天花板和账单都由他人定。自研不保证便宜，但至少把「能不能用得上」的主动权往回收了一点。

当模型的胜负越来越由算力决定，自己造芯片，成了头部公司最贵的一张保险单。

来源：Ars Technica

08-07 · Meta · 编码 Agent
Meta 发布 Muse Code：专攻大型代码库的终端 Agent

Meta 推出 Muse Code 终端编码 Agent，底层是新的 Muse Spark 1.2 模型，定位是「能处理复杂软件里的复杂任务」。

它的卖点不在写一行代码，而在读懂一个大型代码库：规划改动、跨文件修改、跑测试验证，把「改代码」拆成一套可回退的流程。对普通开发者，这类工具把「接手陌生项目」的启动成本降下来一截，是这周开源工具里最接近「拿来就能用」的一个。

编码 Agent 的竞争，已经从「写对一段代码」进到「读懂一整座代码库」。

08-07 · 蚂蚁集团 · 多智能体协作
蚂蚁开源 Avernet：让智能体像组织一样协作

蚂蚁集团开源多智能体协作基础设施 Avernet，社区版已上线，目标是把多个智能体组织起来、像公司部门一样各司其职地分工干活。

单个 Agent 的能力已经见顶，行业正在找「怎么让一群 Agent 一起干活」的答案。Avernet 给出的思路是给智能体搭「组织架构」：谁牵头、谁执行、谁复核，把协作规则写成基础设施，别各写各的。对普通人，这意味着复杂任务不再指望一个全能 Agent 单挑，改成让一队 Agent 分工。

从「一个 Agent 干到底」到「一群 Agent 组队」，多智能体正在从论文走向能用的基础设施。

08-07 · Cloudflare · Agent 浏览器
Cloudflare 发布 Kitesurf：给 AI Agent 用的浏览器长什么样

Cloudflare 推出 Kitesurf，一个为 AI Agent 而非人类设计的云端浏览器，跑在 Cloudflare Workers 的 V8 隔离环境里，用更少的算力让 Agent 完成网页任务。

传统浏览器为人的眼睛设计，Kitesurf 是为 Agent 的「任务」设计：无状态、云端托管、每个 Agent 实例独立隔离，把「让模型自己上网干活」这件事做成可托管的基础设施。对普通人，它意味着 AI 订票、比价、填表这类操作，正在从演示走向有人背书的服务。

Kitesurf：面向 Agent 的云端浏览器 · Cloudflare 官方博客配图

当浏览器不再只服务人类眼睛，上网这件事的主角，第一次多了一类新的「人」。

08-06 · Naïve · 创业自动化
Naïve 融资 2850 万美元：把「开公司」也交给 AI

前 Spotify 员工与「vibe coding」潮更进一步的创业公司 Naïve 拿到 2850 万美元，要把「搭建和运营一家公司」的杂活自动化。

它比 vibe coding 多走了一步：不只生成代码，还接管注册、合规、财务这类开公司的繁琐流程。这类工具的想象空间在于，让「一个人 + AI」从做产品延伸到开公司，把创业的门槛再压低一截。

代码可以 vibe 了，现在公司本身也在往 vibe 的方向走。
