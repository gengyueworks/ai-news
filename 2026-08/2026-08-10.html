08-10 · 宇树科技 · A股
机器人估值变了，宇树先上市：A 股开始给「喂模型的机器人」定价

宇树科技今日启动申购，发行价 150.80 元/股，对应市值约 610 亿元，拟募资约 61 亿元；发行市盈率 219 倍。战略配售名单里，坐着社保基金和深度求索。

看点不只是「人形机器人第一股」。宇树 2023 到 2025 年营收从 1.59 亿涨到 16.99 亿元，2025 年首次盈利 2.78 亿——而且募资近半投向 AI 模型研发，不是产能。一家机器人公司把融资重心压在「软件和模型」而不是「工厂」上，这在 A 股是第一回。

当机器人的估值逻辑开始从「造硬件」转向「喂模型」，A 股的第一只人形机器人股，其实是在给整个赛道定价。

08-10 · OpenAI · 产品
ChatGPT 免费版不限文字次数：OpenAI 开始抢「日常聊天」入口

OpenAI 从今天起取消免费版和 Go 版账户的纯文本对话次数限制，免费用户默认模型换成更小的 GPT-5.6 Luna，并新增「Think」按钮支持更深入的回复。

图片生成、文件上传、语音仍保留独立额度。把最常用的文字聊天做到不限量，瞄准的是「每天都打开」的习惯——入口之争，从模型能力挪到了使用成本。

08-10 · Anthropic · 安全
Anthropic 说基本治好了提示注入：agent 上桌的门槛，又低了一截

Anthropic 工程师 Boris Cherny 表示，通过模型训练已基本解决 Claude 在实际使用中的提示注入威胁；独立基准显示，叠加多层防御后，未见过的间接注入攻击成功率接近 0。

同时 Claude Code 的自动模式将于下周默认开启。提示注入是「agent 敢不敢放出来干活」的拦路虎之一——这一关松动，企业用 agent 的犹豫会少一截。

来源：Anthropic 官方
08-10 · 职场 · 信号
AI 削减入门岗：认知的「公地悲剧」正在发生

讨论聚焦一个新担忧：当 AI 先吃掉初级岗位，新人失去「练手」的土壤——没人再手把手学基本功，行业认知的积累开始断裂。

这被称为「认知公地悲剧」：每个人都受益于一个新人源源不断的环境，但每个公司单独看都觉得「先上 AI」最划算。AI 省下的成本，可能正在透支整个行业未来的基本功。

08-10 · 算力 · 国产
首个全国产 10 万卡超集群投用：国产大模型训练不再「等算力」

首个全国产 10 万卡人工智能超集群正式投用，落子「东数西算」粤港澳大湾区枢纽节点，瞄准万亿参数级国产大模型训练需求。

08-10 · GitHub Models · 退役
GitHub Models 退役了：一个时代的侧写，也是下一个时代的注脚

Simon Willison 记录：GitHub Models 已完成退役，模型 playground 和跨 LLM 提供商的统一 API 服务正式关闭。

这个服务曾让 GitHub Actions 里的代码直接用环境内的 API key 调各家模型。它的关闭更像一个信号：开发者调模型的姿势，已经从「平台搭桥」走向「自带额度直连」。

来源：Simon Willison
08-10 · 工具 · 原型
把文本历史压缩进 SQLite：一个给「记住一切」做的原型

Simon Willison 实验：用 zlib/zstd 把文本修订记录压缩进 JSON 数组存进 SQLite，让应用能低成本保留完整历史。

当 AI 应用要「记住」每一步状态，存储会爆炸。这个原型想的是怎么让「全量历史」变得便宜。让 AI 记住一切的代价，正从「存储成本」变成「压缩算法」的问题。

来源：Simon Willison
