08-04 · LLM · 工具升级
LLM 0.32 发布：推理轨迹、服务端工具、SQLite 日志一起上桌

Simon Willison 发布 LLM 0.32，称这是项目初始发布以来最重要的一次升级。推理轨迹可以输出到 stderr，不污染标准输出；新增 OpenAI Responses、服务端工具、content-addressable SQLite logs；默认模型切到 GPT-5.6 Luna。

对开发者来说，这意味着三件事同时落地：能看到模型「怎么想的」（推理轨迹）、能接服务端工具（不只是本地）、能查历史（SQLite 日志）。以前模型是黑箱，现在从思考到调用到记录，全链路可查。

来源：Simon Willison

前线
08-04 · MiniMax · 本地实测
MiniMax H3 跑进 MacBook：下载 115GB，生成视频接近 45 分钟

Simon Willison 在 M5 Max MacBook Pro 上跑通了 MiniMax H3（PipeNetwork/minimax-h3-mlx）。下载约 115GB，生成一个视频接近 45 分钟。

视频效果不错，但音频因为没给提示，变成了「怪异的语音噪声」。这是本地跑的常态：权重拿到了，提示词还得自己调。当开源视频模型能本地跑，调参的乐趣和烦恼，都回到了用户手里。

来源：Simon Willison

08-04 · MCP · 工具链重组
MCP 2.0 之后：工具接入开始围绕「无状态」重做

Simon Willison 继续围绕 MCP 工具链做实验，说明 7 月 31 日的规范变化已经开始带动工具链更新。

他已经在 LLM、Datasette、MCP 之间打通更多工作流。对开发者来说，这意味着 agent 工具接入会更像普通 Web 服务，而不是复杂的协议握手。

来源：Simon Willison · MCP 无状态
