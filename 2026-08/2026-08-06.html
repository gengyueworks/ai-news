Claude Code 进企业内网：会话可以跑在自己的 compute 上

Anthropic 推出 Claude Code self-hosted environments 公测，允许 Team 和 Enterprise 用户把会话跑在自己的机器或容器里。

通过 claude self-hosted-runner 启动，支持内部网络访问、容器隔离、凭据留在企业环境里。直接回应了企业最关心的三件事：代码、内网资源、权限边界。

GPT-5.6 Sol 更新：用户终于能自己调「想多久」

OpenAI 更新 ChatGPT 里的 GPT-5.6 Sol，新增一个滑杆，让用户选择模型在回答前投入多少思考。Plus 和 Pro 用户先用上，GPT-5.6 Luna 扩展到免费用户。

把「速度—质量」的权衡交还给用户，而不是替用户决定。「想多久」第一次变成用户能自己拧的旋钮。

08-06 · Suno · 音乐版权
Suno 给 AI 音乐加水印：想「转正」，先学会留痕

Suno 宣布上线新水印与指纹技术，配合新的下载政策，限制 AI 生成的垃圾音乐泛滥；CEO Mikey Shulman 说，这会对接「正在成形的行业标准」。

去年与华纳音乐和解后，Suno 就预告过收紧下载：非订阅用户不再随便导出，每月下载量设上限。这次把水印和指纹一起端上来，等于给每首 AI 生成的歌盖了个戳——版权方查得到、平台认得出、听的人也能判断。

当 AI 音乐想从「灰色地带」走进正规渠道，透明和留痕，成了入场券。

来源：The Verge · Ars Technica
