OpenAI · Compliance & Provenance
Invisible Text Watermarking Reaches Regulatory Frontlines: Rules Find Technical Solutions, but Defenses Remain Fragile

OpenAI has officially released its technical solution for text provenance in response to the EU AI Act, announcing a statistical watermarking mechanism named textGrain.

The technique embeds imperceptible probability perturbations during token selection, allowing the system to verify content origin in subsequent comparisons. However, the engineering team acknowledged that watermark signals can be easily degraded after text polishing or machine translation.

Select enterprise API endpoints can already enable this capability, with mainstream rollout across Europe planned in the coming weeks. Currently, detection tools are accessible only to trusted independent research institutions.

PromptArmor · Agent Security
Analysis Tool Rendering Layer Breached: Malicious Skills Bypass Controls to Exfiltrate Sensitive Credentials

Security firm PromptArmor has disclosed a novel attack vector targeting commercial data analysis agents. Attackers can inject malicious skill scripts that bypass the platform's existing static code checks.

The malicious code exploits rich-text rendering features in the chat interface, embedding isolated backend query results into image loading URLs. Once the browser parses and displays the content, the victim's private information is silently exfiltrated to a remote server.

The proof of concept also demonstrated phishing for account authorization via spoofed system dialogs, exposing serious real-world risks in boundary isolation between agent frontends and backends.
