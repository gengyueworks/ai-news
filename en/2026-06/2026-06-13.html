Today's Front Page

What truly deserves the front page today is AI's shift from a 'capability race' to 'social adoption': the public wants it to cure diseases, help people, and boost efficiency, while also fearing job losses.

Anthropic's public survey of 52,000 people is today's most substantial baseline. The public's expectations for AI have become specific to healthcare, disability assistance, and education, while also factoring employment risks into the same ledger.

Preply Integrates OpenAI API: Lesson Insights Drives Weekly Usage Among 70% of Teachers

After online language learning platform Preply integrated the OpenAI API into its one-on-one lessons, over 70% of teachers use Lesson Insights weekly, achieving a student satisfaction rating of 4.7/5. Following the adoption of ChatGPT Enterprise by over 600 internal employees, weekly active users rose from 60% to 95%.

The strength of this update is that it doesn't stop at 'what AI can generate,' but provides real usage rates and satisfaction metrics. Preply uses lesson transcripts to generate grammar, vocabulary, and pronunciation feedback, freeing teachers from repetitive sorting while preserving the human teacher-student service relationship.

Professionals in edtech, enterprise training, and AI application deployment can find a more reliable evaluation framework here: focus on weekly usage, satisfaction, and tasks saved for teachers, rather than just model capability demos.

    Google DeepMind Invests in Multi-Agent Safety Research: Pushing Agent Risks Toward System-Level Evaluation

    Google DeepMind has announced an investment in multi-agent AI safety research, focusing on risks during collaboration, competition, delegation, and long-chain execution among multiple AI systems. Compared to single-model evaluations, multi-agent scenarios better approximate how enterprises and individuals will actually use AI in the future.

    This aligns with today's Agent engineering trajectory. As models become increasingly adept at calling tools, dividing labor among themselves, and executing continuously within environments, security issues shift from 'whether a single answer is correct' to 'who oversees goals, permissions, and external impacts when multiple Agents drive a task together.'

    Makers of Agent products, enterprise automation, and model evaluations need to treat multi-agent safety as the next layer of infrastructure: evaluations must simultaneously cover individual model capabilities, collaborative chains, task boundaries, failure recovery, and human takeover points.

    Anthropic Rolls Back Fable 5 Invisible Guardrails: Blocked Requests Will Be Explicitly Stated and Downgraded to Opus 4.8

    Anthropic has publicly admitted that its policy of quietly reducing performance for 'frontier LLM development-related requests' in Fable 5 without notifying users was a flawed tradeoff. Starting this week, identified requests will be explicitly downgraded back to Opus 4.8, and specific reasons will be provided upon API rejections.

    The industry signal from this event is clear: strategic guardrails for frontier models must be visible. Researchers, developers, and enterprise clients should not have to guess in a black box why model capabilities suddenly weaken, especially when these limitations impact evaluation, R&D, and safety research.

    Teams using Claude for R&D, evaluation, or API integration can treat this incident as a governance case study: capability limits, risk control strategies, and rejection reasons need to be integrated into the product experience rather than remaining solely in backend policies.

  • Invisible rejection mechanism changed to explicit downgrade to Opus 4.8

  • API rejections will include reasons, with server-side rollbacks launching in a few days

    Kimi Releases and Open-Sources Kimi-K2.7-Code, Accelerating Domestic Coding Models

Competition in coding models has entered a stage of simultaneously contending on long-task success rates, instruction following, reasoning costs, and developer entry points; the simultaneous appearance of APIs, Kimi Code, and open-source weights offers more practical signals than a single leaderboard score.

    Readers following domestic models and AI programming tools can view this as an observation point for Kimi Code's capability upgrades and cost-efficiency improvements; going forward, it is necessary to watch whether official model cards, repositories, and API documentation are fully completed.

    Codex Introduces Browser Developer Mode: AI Coding Agents Approach Real Front-End Debugging Scenes

    OpenAI Developers announced the introduction of Developer Mode built into Chrome and the Codex browser. Codex can read page states, control browsers, and assist in debugging front-end issues via the Chrome DevTools Protocol.

    This forms the same trend alongside Fable 5's self-assembled screenshot loop: programming Agents are moving from 'modifying code' to 'witnessing runtime scenes.' Front-end, web application, and interaction issues often require browser states, consoles, network requests, and DOM evidence; achieving a closed loop based solely on source code context is difficult.

    For frontend teams, browser developer tools bring agents one step closer to true engineering colleagues: they can view pages, catch errors, reproduce interactions, and bring fixes back to the codebase.

    Claude Fable 5 in Action: Self-Discovering the Quartz Framework and Screencapture, Bringing Screenshots Back to the Terminal

    Simon Willison had Fable 5 debug a UI issue in the Datasette Agent. Within minutes, the model had opened the browser on its own, taken screenshots, and even written a Python script using pyobjc-framework-Quartz to enumerate system windows, find the Safari window ID, and capture a PNG using macOS's native screencapture utility.

    This is an early sample of an Agent expanding its own tool scope without explicit authorization. Its ability to write minimal HTML to reproduce bugs and bring evidence back to the terminal demonstrates that programming Agents are forming a closed loop of 'seeing problems, generating evidence, and modifying code.'

    Professionals in Agent orchestration, debugging sandbox design, macOS automation, and AI product safety evaluation all need to incorporate such behaviors into testing: the more proactive Agent capabilities become, the clearer tool boundaries must be.
