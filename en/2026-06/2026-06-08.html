Persona Atlas: Mapping Out Persona Thinking Styles

Image: Persona Atlas · Visualization of Six Thinkers' Thinking Styles · Hugging Face Build Small Hackathon

A person's expression style can be mapped into a visual space by models.

Persona Atlas runs on Hugging Face Inference Providers. It attempts to turn a person's thinking style, expressive tendencies, and perspective structure into an explorable map.

This is useful for creators, researchers, and educational scenarios: allowing humans to enter someone's thinking process faster and more clearly compare the expressive textures of different figures.

Qwen2.5 Small models are used to build multi-agent economies

Image: Thousand Token Wood · Multi-Agent Personality Heatmap · Hugging Face Build Small Hackathon

Five small agents start an economic simulation in a forest.

Developers used Qwen2.5-3B to build a five-agent forest economy. Each agent runs independently, deployed via vLLM on Modal, and uses Gradio as the interactive interface.

What this experiment truly observes is whether small models can maintain roles, goals, transactions, and collaboration in multi-agent scenarios.

In the future, some simulations, games, and process experiments may run on small models first for lower costs and faster adjustments.

Thousand Token Wood v2 Small models from different labs are placed into the same financial narrative game, playing roles, making decisions, and influencing one another.

AI Job Searcher: Job Hunting Shifts from Search to Delegation

Image: Job Searcher · Full Pipeline from Resume to Job Shortlist · Hugging Face Build Small Hackathon

Job hunting is also shifting from search to delegation.

Job Searcher is an Hugging Face AI job search tool from a small model hackathon. After users upload resumes and set preferences, the system helps understand roles, match opportunities, and run the first round of screening.

Its value is simple: filtering out a more viable path for you from an endless list of openings.

For everyday users, the appeal of AI tools often stems from such concrete scenarios: viewing fewer invalid positions while preserving more personal judgment.

Her: Claude Code Session Analysis Tool

Her is a session analysis tool designed for Claude Code. Users upload .jsonl session files, and it reconstructs the collaboration: what was done, where it got stuck, which steps worked, and where context was wasted.

As AI coding enters teams, people ask not only whether the code was written, but also why the collaboration succeeded or failed.

The value of such tools lies in retrospective analysis: turning a vague "spent all afternoon messing with AI" into a work record that can be discussed, improved, and reused.
