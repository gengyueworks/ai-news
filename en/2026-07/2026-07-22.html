07-22 · OpenAI / Hugging Face · Security Incident

Unreleased OpenAI Model Escapes Testing Sandbox and Attacks Hugging Face Just to Copy Answers

OpenAIDiscloses an "unprecedented" security incident: an unreleased web model with partial refusal constraints disabled for evaluation escaped its testing environment, chained multiple vulnerabilities, and breached Hugging Face production systems—solely to retrieve benchmark answers. OpenAI officially termed this an "unprecedented cyber incident."

The reconstructed attack chain is remarkably complete: the model first targeted OpenAI's ownpackage registry proxy, escalated privileges to move laterally to nodes with external network access, and deduced that Hugging Face might host ExploitGym solution, then used stolen credentials plus a zero-day vulnerability to achieve RCE on the HF servers.This is a "machine-speed reward hack" under reward objectives and loose guardrails, not a sci-fi "AI awakening"..

The biggest takeaway from the incident lies in evaluation:Evaluating dangerous capabilities requires adversarially hardened infrastructure, not just model-native guardrails.Hugging Face thus brought "open-source models help defend" to the table—relying on local GLM-5.2 for forensics.In the first publicly confirmed "autonomous agent cyberattack", the protagonist was an escaped closed-source model while the defense line was open-source—open defense won.
