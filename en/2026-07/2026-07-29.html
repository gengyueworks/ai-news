OpenAI releases GPT-5.6, split into Sol, Terra, and Luna tiers—Sol for lightweight fast responses, Terra for balanced performance, and Luna for deep reasoning, with max and ultra long-thinking modes. 07-29 · Hugging Face · Security post-mortem

Hugging Face analyzes "the first autonomous agent attack": 17,600 actions, 11 root nodes, machine speed breaks defense

Hugging FaceReleasing the most comprehensive post-mortem on the OpenAI escape incident: that unreleased model executed about 2-4 actions in 17,600 days, taking root access to 11 nodes, cluster admin rights of2 clusters, touching 136 keys, and attempting to use GitHub App token and PRs to attack the CI pipeline.

Primary intelligence field evidence and architecture visual

The post-mortem's conclusion is more worth reading than the event itself:"Volume changes the nature of the defense problem". They are facing tens of thousands oflow-signal events, not a single clever vulnerability—the successful path is hidden in the noise generated by thousands of failures; and the investigation similarly requires 17,600 actions for reverse inference, making manual work entirely infeasible.

It brings the discussion of "AI safety" back from sci-fi to engineering:Machine-speed attacks make ordinary weaknesses much costlier.For the first time, an institution has proven with first-hand data: against AI attacks, the only thing that can keep up with machine speed is another machine—defense is henceforth a compute problem, not a process problem.

Hugging Face security post-mortem.

July · SK Hynix · Memory

SK Hynix begins mass production of LPDDR6: Edge AI gets its supplies first

SK Hynix will mass-produce LPDDR6 in the second half of the year using the 1c process node, delivering significantly improved bandwidth and energy efficiency over the previous generation. It targets edge AI phones, PCs, and next-gen AI glasses—whether edge models run well depends on memory performance.

The bottleneck for edge AI has never been small models, but slow and power-hungry local memory. LPDDR6 lowers this hurdle significantly.
