MCP Releases Stateless Candidate, Enabling "Stateless" Agent Calls for the First Time

On July 28, MCP released the stateless specification candidate, officially graduating Tasks and MCP Apps. Calls no longer require persistent connections or session state, carrying all context in a single request.For governance, the specification is handed over to the AAIF and Linux Foundation for co-management, preventing any single company from controlling the steering wheel.

Primary intelligence field evidence and architecture visual

The protocol decomposes "thinking steps" into universally callable parts, sparing developers from session-state headaches and making agents easier to assemble and swap.
