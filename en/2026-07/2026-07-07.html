07-06 · Reuters · Three sources familiar with the matter

Meituan Open-Sources LongCat-2.0: Trillion-Parameter Model Trained on Domestic Chips, but the Real Hard Battle Has Just Begun

China's first trillion-parameter LLM trained and inferred entirely on domestic computing poweris officially open-sourced today. Meituan announced the open-source release of LongCat-2.0 with a total of 1.6 trillion parameters and an average active parameter count of about 48 billion. Released under the MIT license, it runs end-to-end on a cluster of 50,000 domestic computing cards. Domestic chipmakers including Huawei Ascend, Moore Threads, and MetaX have confirmed support.

Primary intelligence visual archive

This is far more than a demo—LongCat-2.0 ran anonymously as "Owl Alpha" on OpenRouter for two months, becoming one of the platform's most-used coding models,achieving a SWE-bench Pro score of 59.5, surpassing GPT-5.5 (58.6) and Claude Opus 4.6 (57.3).. For developers and agent builders, this marks the emergence of an MIT-licensed, near-state-of-the-art, and ultra-low-cost option.

OpenRouter pricing for LongCat-2.0: $0.75 / M tokens input, $2.95 / M tokens output, far below closed-source flagships.

  • Meituan LongCat-2.0: 1.6T-Parameter MoE, MIT License
  • Trained on 50,000 domestic cards (Huawei Ascend), first time running a trillion-parameter model purely on domestic hardware
  • SWE-bench Pro 59.5 (beats GPT-5.5); top-tier popularity on OpenRouter after two months of anonymous testing
  • Supports 1M-token context with targeted enhancements for agentic coding
  • Pricing: $0.75 input / $2.95 output per million tokens

Tencent Hunyuan Hy3 Open-Sourced: 295B Model Runs on vLLM Day One, Licensing Matters More Than Parameters

07-07 · Anthropic · Mechanistic Interpretability

Anthropic Uncovers Claude's Internal "Global Workspace"—Not to Make the Model Smarter

Anthropic Research: A "global workspace"-style structure exists inside Claude, concentrated in a tiny fraction of activations, termed J-space. The core claim is not about "chain-of-thought extraction," but identifying a privileged internal representation layer—reportable, controllable, and participating in flexible reasoning.

Primary intelligence visual archive

Why the Research Community is Shaken: Neel Nanda calls it "the best evidence yet for a working memory mechanism," and Lindsey suggests understanding this privileged space may be key to grasping LLM cognition. From a practical standpoint—research shows it can expose hidden concepts early, detect prompt injections, and reveal internal "malicious-related" features before verbalization.It provides leverage for auditing and intervening in models, not philosophical propositions.

Controversy Follows: Anthropic's framing used the word "consciousness," drawing criticism for overclaiming. The community used CKA similarity across 38 open-source models, finding layer/depth organization highly universal—holding true across unrelated families like Llama and OLMo.

Regardless of how the "consciousness" debate ends, a new path for intervention has been opened—which is the true weight of this research.

Copilot Integrates Open-Weight Code Model for the First Time

GitHub Announces Kimi K2.7 Code Now generally available (GA) as an open-weight model in GitHub Copilot. This is the first open-weight model option in the Copilot model picker—For the first time, developers can select open-source models directly in the main Copilot interface, no longer restricted to closed-source options from OpenAI or Anthropic.

Real impact for developers: model choice is now built directly into the official product interface rather than requiring manual geek workarounds. 07-06 · Rest of World · Chinese web novels & AI

Web Novel Platforms Tighten AI Restrictions as Reader Patience Hits Its Limit

Using AI to mass-produce web novels was once seen as a shortcut to boost productivity.But readers have had enough. Fanqie Novel (ByteDance) has limited daily publishable word counts, rejecting over 104,000"low-quality" submissions in June alone; Jinjiang Literature City founder Huang Yanming explicitly requested that authors use AI strictly for research and proofreading, while inviting readers to report suspected AI-generated articles.

The trigger was a loss of quality control. Readers on Xiaohongshu have been sharing screenshots of leftover AI prompt words, strange metaphors, and boilerplate AI phrasing in novels. One reader noted: "Reading something hastily mass-produced is just a waste of my time." Meanwhile, InkOS (a multi-agent automated novel writing system) built by Beijing developer Ma Junxian has surpassed 50,000+ downloads, with some users even making money off AI-generated novels.

  • Fanqie limits daily word counts, rejecting 104k low-quality submissions in June
  • Jinjiang mandates AI strictly for assistance, encourages reader reporting
  • InkOS multi-agent writing system hits 50k+ downloads
  • Core Issue: Is AI a Productivity Tool or a Junk Generator?
