07-31 · DeepSeek · Model

DeepSeek V4-Flash official public beta launched: Flash's Agent capabilities surpass the Pro preview, but the real hard battle has just begun

DeepSeek V4-Flash public beta launched.

Primary intelligence field evidence and architecture visual

On July 31, the DeepSeek-V4-Flash-0731 official API launched in public beta. Total size 304B, active size 13B, supporting 1M context window. Architecture and size remain unchanged; official sources state that only post-training was redone this time, with a primary focus on enhancing agentic capabilities. After hands-on testing, Simon Willison noted it "significantly exceeds expectations for its scale," specifically praising its cost-performance ratio. The accompanying Harness capability also debuted.

The fact that a model can leap a tier with the exact same skeleton simply by changing its training strategy is most interesting not for its benchmark scores, but because it further compresses the old narrative of "stacking parameters to the max." V4-Flash is now deployed within DeepSeek's own Agent pipelines, allowing scripts that previously took an internal team a whole day to write to be handled and executed autonomously by agents.

The second half of the model race is about post-training, not parameter stacking. DeepSeek used Flash to answer this question for itself.

Sources: DeepSeek API Changelog · Hugging Face · Simon Willison Hands-On Review

07-31 · MiniMax · Multimodal

MiniMax H3 released: the first open-source multimodal model at 0.8 CNY/sec, but the real hard battle has just begun

On July 31, MiniMax released H3, a multimodal model supporting simultaneous text, image, audio, and video input. It can directly output 2K video clips up to 15 seconds of synchronized audio and video; video generation is priced at 0.8 CNY/sec (2K), approximately one-third of comparable flagships. MiniMax also confirmed that H3 will be open-sourced in the coming days, marking the company'sfirst open-source multimodal model.

Primary intelligence field evidence and architecture visual

Compared to the price war in text models, H3 moves the battlefield to video, where compute overhead is orders of magnitude greater than text. Achieving 0.8 CNY/sec relies on H3's internal unification of audio and video codecs into a single latent space, eliminating the waste of multiple re-encodings. Several creators with early API access noted that the cost of running 30 seconds on Runway in the past can now run a complete commercial film.

As the price war spreads from text to video, H3 bundles "open source + low price," lowering the barrier to creation once again.

MiniMax H3 released.

07-31 · smevals · Evaluation Tool

smevals launched, turning "how to evaluate models" into a set of YAML files

Simon Willison and Jesse Vincent's Prime Radiant Labs released smevals, a lightweight eval framework for comparing models, prompts, and harnesses. Run once, evaluate once, and generate a static report entirely via the command line.

Primary intelligence field evidence and architecture visual

Usage is simple enough to fit into a single paragraph:uvx smevals run path-to-eval/ -m gpt-5.5 -m claude-opus-4.6 allowing different models to run the same set of tasks; after running, grade and finally build generating a hostable static report. Useful for content teams as well, you can use it to test "which model is better suited for writing headlines/summaries/scripts" rather than picking models based on intuition.

Model evaluation has shifted from metaphysics to "a set of YAML files," marking the first time the toolchain has turned evaluation into accessible infrastructure for everyone.

Sources: Prime Radiant · GitHub · Simon Willison

07-31 · MCP · Protocol Upgrade

MCP shifts to a single HTTP request, Lowering the barrier for agent tool integration

Simon Willison summarizes MCP 2.0 (2026-07-28 spec), noting that "stateless MCP" simplifies both client and server development. While older versions required session initialization before tool calls, the new spec completes everything in one request.

Willison built mcp-explorer, datasette-mcp, llm-mcp-client three projects on the new spec the same day. His verdict is clear: compared to giving agents a shell, MCP offers better auditability and control, leaving a clear trace of what agents can do and what they invoke.

With a single protocol upgrade triggering a toolchain overhaul, the connection model between agents and tools is shifting from "sessions" to "single requests."

MCP becomes a single HTTP request.

07-31 · Creators · Experience Shifts

Running product storyboards with H3, Ten minutes for a usable motion ad

A video creator used H3 to generate transitions and dynamic effects based on a storyboard script and reference images. She noted that the text and UI details rendered more stably than expected, turning what used to take a post-production team two days into afirst draft completed in ten minutes.

She produced a 30-second splash screen ad for a beauty app: she wrote the script, drew the storyboards herself, and picked transition reference images from a stock library. H3 generated 6 shots based on the storyboards, maintaining consistent subjects and natural transitions between cuts. Notably, the text layer names written directly in her PSD file were read accurately without retranslation, which she found particularly seamless. The first draft passed client review without modifications, leaving 90% of her time spent on selecting the BGM.

When generative models can handle professional terminology like "storyboards," the relationship between creators and tools evolves from contract manufacturing to true partnership.
