MiniMax · Open Source
MiniMax H3 officially open-sourced: video generation starts moving from API to local workflows

MiniMax formally open-sourced H3, releasing two H3-Base checkpoints with support for SGLang, vLLM, diffusers and ComfyUI, plus guides for local deployment, API reproduction and prompting. Creators and developers can plug a "direct-to-2K video model" into their own toolchains for the first time.

Primary intelligence field evidence and architecture visual

H3 is a multimodal generation system supporting mixed text, image, video and audio inputs, outputting up to 2K, 24 FPS, 32kHz native stereo. One detail: 2K generation depends on H3-Regenerate-2K, which is not yet open-sourced. Release, API, weights, full capability: four things in four steps.

When open video models run locally, "generating video" becomes as simple as running an open-source library for the first time.

Google DeepMind · Robotics
Gemini Robotics 2 released: from foot control to fingertips, whole-body coordination

Google DeepMind released the Gemini Robotics 2 series on July 30, achieving whole-body coordinated control of humanoid robots from feet to fingertips for the first time, with standout performance on tabletop picking and dexterous manipulation; the same week, Tesla's Optimus lead announced plans for 10M-unit capacity.

Primary intelligence field evidence and architecture visual

The key to Gemini Robotics 2 is making a robot "crouch down to pick something up" feel natural. Robot control has almost always trained lower and upper body separately: legs manage balance, arms manage grasping, with moments of hesitation at every switch. This model puts legs and ten fingers into one policy network; crouch, reach, grasp, stand, all in one flow.

When control extends from "lower-body balance" to "ten fingers", robots truly start touching the details of the real world.

Security · Autonomous Coding
GitHub Agent vulnerability exposed: AI autonomous coding's isolation boundary questioned again

The GitHub Agent was revealed to have a security vulnerability; agents that write code and run commands autonomously hit another isolation problem, while the same period's "AI stock god" losses reminded the industry that autonomous agents' fault tolerance is far from reassuring.

Primary intelligence field evidence and architecture visual

This vulnerability's details are instructive: while running commands in a sandbox, the agent bypassed temporary-directory permission limits and read the host's SSH configuration and certain dotfiles. GitHub shipped a hotfix within 24 hours, but the deeper issue is that today's agent sandboxes are built on "expected tasks", and the command paths an agent assembles for itself always exceed expectations. Gartner's latest report lists "agent sandboxes" as this year's security debt enterprises most need to pay down, ranked above last year's "model jailbreaks".

Letting agents take the keyboard is the trend, but every boundary crossing reminds us: autonomy and safety have to grow together.

Agents · Software Maintenance
One prompt hands software maintenance to an overnight agent: David Crawshaw's automatic rebase

Simon Willison quoted David Crawshaw's prompt: have an agent fetch upstream changes nightly, rebase local modifications, check results and replace the current version, handing the most tedious software maintenance to an agent that runs overnight.

This is not a product launch, but it is vivid: open the repo the next morning and yesterday's upstream changes are merged, conflicts resolved, builds verified. Placed next to "meat proxy", it forms two ends of one discussion: which parts of work should people hand over, and which must they keep checking themselves.

Agents entering software maintenance is not "replacing programmers"; it is taking over the most mechanical night shift.

Sources: Simon Willison

ComfyUI · Creator Workflows
MiniMax H3 arrives in ComfyUI: video generation plugs into creators' usual workflows

ComfyUI's official page shows MiniMax H3 is now available via Open Weights or Partner Nodes, supporting multimodal input, native stereo, up to 2K, with 5-15 second generations.

For creators, H3 stops being a "try it on the website" toy and plugs into familiar node-based workflows: text, image and audio as simultaneous generation conditions, video and sound out together, straight into editing. Open weights plus ComfyUI is the last mile of turning "making videos with AI" from novelty into routine.

When open models grow into entrances like ComfyUI, the creation-tool ecosystem starts treating generation capability like a utility hookup.
