# AI News · 开放查阅版

前沿信号流——AI每天在变什么，人在怎么选。

本仓库为 **AI News 开放查阅版（Public Edition）**，通过 GitHub Pages 免费对外提供 2026 年 6 月至 7 月全部历史日报及周回顾的在线查阅。

---

## 📖 版本分层策略

| 版本 | 内容范围 | 渠道 |
|------|---------|------|
| **开放查阅版 (本仓库)** | 2026 年 6 月 - 7 月完整历史日报 (共 59 份日报 + 2 份周回顾) | GitHub Pages (`gengyueworks/ai-news`) |
| **完整订阅版** | 2026 年 8 月起最新每日更新 + 完整情报档案库 | 读者付费订阅通道 |

```text

```

## 🛠️ 构建与维护

运行构建脚本自动完成公开版页面转换（移除缺失链接、注入底部固定订阅 Banner 等）：
