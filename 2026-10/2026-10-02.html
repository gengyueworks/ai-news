Anthropic · 开发者工具 · 2026-10-02
Claude Code 开放 mods 扩展，封闭式代码助手终于让位给可编程插件钩子

Anthropic 正式为命令行开发工具 Claude Code 推出 mods 机制。开发者现在可以使用极简的 TypeScript 函数，直接挂接到核心事件流中。

该机制支持在执行前改写系统提示词、拦截或重试工具调用，并且能够针对敏感权限请求设定自定义审批逻辑，甚至在终端内注入定制 UI。

这些自定义函数可以通过插件形式打包与分发。以往高度同质化的代码助手，开始将执行控制权直接交还给一线工程团队。

Modal · 计算基础设施 · 2026-10-02
Modal 发布 VM Sandboxes，智能体运行环境从小容器切换到完整虚拟机

云算力平台 Modal 宣布旗下 VM Sandboxes 正式进入通用可用状态。开发者只需在配置中指定特定运行时参数，即可为自主执行任务的智能体分配一套完整的 Linux 操作系统。

新环境完整支持 Docker、FUSE 文件系统与内核级调试功能，同时保留了原有的亚秒级冷启动与动态内存调度优势。官方统计显示早期测试用量已突破 2000万 个虚拟机实例。

伴随智能体复杂度的提升，受限的容器沙盒难以承载真实编译需求，底层运行环境正加速向完整系统镜像演进。

OpenAI 拦截大规模推理蒸馏行动，跨云平台防护差异带来新缺口

Xiaomi · 模型评测 · 2026-10-02
小米 MiMo-V2.6 登陆智能体基准，净提升 3.17% 跻身开源前列

Xiaomi 团队研发的 MiMo-V2.6-Pro 与 Flash 两款架构正式接入评测体系。在累计超过 8100 次真实智能体会话交互测试中，Pro 版本取得了 +3.17% 的净提升表现。

其在任务最终确认率指标上达到 +7.35%，位居当前开源梯队第二名，综合执行稳定性较上一代产品提升了 9 个名次。

LangChain · 智能体工程 · 2026-10-02
LangChain 验证动态模型路由，单任务中位调用成本下降 64%

LangChain 在开源编码智能体 Open SWE 中部署了动态模型路由器。通过在近千个真实测试线程中的对比验证，中位执行成本从 $2.61 降至 $0.94。

在成本压缩超过六成的同时，代码合并成功率维持在 29.2% 对 27.3% 的平稳区间，没有出现质量下滑。

工程实践证明，在控制流中合理分流低风险子任务，比全局依赖昂贵模型更具部署可行性。

ChatGPT · 协议生态 · 2026-10-02
ChatGPT 支持直接部署 MCP 服务，智能体协议从本地配置走向云端托管

ChatGPT 现已允许用户在平台内直接编写并托管 MCP 服务器。构建完成的上下文服务可以一键打包为跨端插件，同步分发至网页、移动端与桌面环境。

系统为自建服务提供了权限隔离选项，支持完全私有调用或向指定协作人员开放。过去繁琐的本地网络转发环节被整合为标准化的云端托管功能。

协议互通门槛的降低，正促使更多外部工具接入大模型的实时上下文通道。

Perplexity · 异步协同 · 2026-10-02
Perplexity 开放邮件委托入口，把长程任务搬进日常收件箱

Perplexity 正式开放旗下 Computer 系统的邮件任务通道。用户无需登录专属账号，只需将需要处理的分析诉求通过邮件发送或抄送至指定地址。

后台智能体会自动承接上下文并在云端完成多步骤执行，所有中间步骤均保留完整的审计记录与网页追溯视图。这种异步处理形态降低了复杂任务的操作负担。

传统办公通讯协议正在成为承接后台自动化任务的高频入口。

Black Forest Labs · 多模态生成 · 2026-10-02
FLUX 3 Image 上线多平台，支持原生 4K 多轮编辑且不伤及背景

Black Forest Labs 推出的主力视觉模型 FLUX 3 Image 正式登陆 Krea 与 OpenRouter 等服务平台。新架构支持最高 4K 分辨率的原生画质渲染。

OpenRouter · 算力经济 · 2026-10-02
OpenRouter 发布成本权衡框架，推动推理预算从盲目顶配转向实测过线

模型聚合平台 OpenRouter 发布了面向智能体开发者的成本与质量权衡框架。该方案建议放弃单纯追踪跑分榜首的做法，改为建立具体的任务质量基准线。

开发人员可提取数十组特定业务样本，对低、中、高三个价位的模型展开标准化打分，计算每个质量分数的实际边际开销，最终选出稳定跨过及格线的最经济组合。

精细化度量每笔调用的产出比，正在成为企业控制算力账单的核心规范。
