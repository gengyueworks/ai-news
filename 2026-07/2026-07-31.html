07-31 · DeepSeek · 模型
DeepSeek V4-Flash 正式版公测：Flash 的 Agent 能力，反超 Pro 预览版

DeepSeek V4-Flash 公测。

7 月 31 日，DeepSeek-V4-Flash-0731 正式版 API 上线公测。总量 304B、激活 13B，支持 1M 上下文——架构和尺寸不变，官方说这次只重做了后训练，重点增强 agentic 能力。Simon Willison 实测后认为它「明显超出这个体量该有的表现」，特别提到性价比。配套的 Harness 能力也首次亮相。

同一副骨架、只换一套训练策略，模型就能跃迁一个档位——这件事最有意思的地方，不是分数，是它把"参数堆到顶"的旧叙事再压低了一寸。V4-Flash 现在被部署到了 DeepSeek 自己的 Agent 流水线里，原本一个内部团队要写一天的脚本，现在让 Agent 自己接、自己跑。

模型竞赛的下半场，拼的是后训练，不是堆参数——DeepSeek 用 Flash 替自己回答了一次这个问题。

07-31 · MiniMax · 多模态
MiniMax H3 发布：首款开源多模态模型，0.8 元/秒

MiniMax 7 月 31 日发布 H3——一款支持文字、图像、音频、视频同时输入的多模态模型。它能直出 2K 视频片段，最长 15 秒音画一并生成；视频生成定价 0.8 元/秒（2K），约为同类旗舰的三分之一。MiniMax 同时确认 H3 将于未来几天开源，是公司第一款开源多模态模型。

和文本模型那一轮的价格战比，H3 把战场挪到了视频——而视频的算力开销比文字大几个量级。能压到 0.8 元/秒，靠的是 H3 内部把音视频编解码统一到了同一个潜空间，省掉了多次重编码的浪费。几位拿到早期 API 的创作者说，过去用 Runway 跑 30 秒的成本，现在可以跑满一条完整的广告片。

价格战从文本烧到视频，H3 把"开源 + 低价"绑在一起，创作的门槛又被砍了一刀。

MiniMax H3 发布。

07-31 · smevals · 评测工具
smevals 上线：把「怎么评模型」做成一组 YAML 文件

Simon Willison 与 Jesse Vincent 的 Prime Radiant 实验室发布 smevals，一个小型 eval 框架，用来比较模型、提示词和 harness。跑一次、评一次、出一份静态报告，全命令行完成。

用法简单到可以塞进一段话：uvx smevals run path-to-eval/ -m gpt-5.5 -m claude-opus-4.6 就能让不同模型跑同一组题；跑完再 grade，最后 build 成一份可托管的静态报告。对内容团队也实用——你可以拿它测「哪个模型更适合写标题/摘要/脚本」，而不是靠感觉挑模型。

模型评测从玄学变成「一组 YAML」，工具链第一次把评测做成了谁都能跑的基础设施。

来源：Prime Radiant · GitHub · Simon Willison

07-31 · MCP · 协议升级
MCP 变成一次 HTTP 请求：agent 工具接入门槛降了

Simon Willison 总结 MCP 2.0（2026-07-28 规范），认为「无状态 MCP」让客户端和服务端都更好写。旧版要先初始化 session 再发工具调用，新版一次请求就能完成。

Willison 当天就基于新规范做了 mcp-explorer、datasette-mcp、llm-mcp-client 三个项目。他的判断很直接：相比给 agent 一个 shell，MCP 更容易审计和控制——agent 能做什么、调用了什么，都有迹可循。

协议一次升级，整个工具链跟着重做——agent 和工具的连接方式，正在从「会话」变成「一次请求」。

MCP 变成一次 HTTP 请求。

07-31 · 创作者 · 体验变化
用 H3 跑产品分镜：十分钟，一段能用的广告动态

一位视频创作者用 H3 按分镜脚本加参考图生成转场与动态特效，说文字和 UI 细节的呈现比预期稳，过去要等后期团队两天的活，现在自己十分钟出初稿。

她给一个美妆 App 出了一条 30 秒的开屏广告：脚本她写，分镜她自己画，转场参考图也是她从素材库里挑。H3 按分镜跑了 6 段镜头，主体一致、镜头之间衔接自然，文字部分甚至直接读了她写在 PSD 上的图层名而不是再翻译一次——这是她觉得最顺手的地方。第一稿没修就过了客户，剩下 9 成时间花在选 BGM。

当生成模型接得住「分镜」这种专业语言，创作者和工具的关系，从代工变成搭档。
