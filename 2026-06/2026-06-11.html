DiffusionGemma：文本生成速度提升4倍的开源扩散模型

Google DeepMind 发布开源实验模型，用扩散技术突破自回归逐 token 生成瓶颈。

Google DeepMind 发布开源实验模型 DiffusionGemma，采用文本扩散技术，突破自回归逐 token 生成瓶颈。

Simon Willison 亦发文关注此模型，指出文本模型路线并非只有自回归一种方向。如果扩散式文本生成继续成熟，本地交互、长文草稿和低延迟工具链会多一条技术路线，速度和延迟会继续成为模型路线竞争的一部分。

  • 生成范式：扩散式文本生成，非逐 token 自回归
  • 速度信号：文本生成速度提升约4倍
  • 路线意义：文本模型生成方式仍在分岔，端侧体验和推理成本可能因此改变

来源：Google DeepMind · deepmind.google ｜ Simon Willison · simonwillison.net

GitHub Copilot CLI 接入语言服务器，获得真实代码智能

终端里的 Copilot 开始靠近 IDE 级代码理解。

GitHub 介绍了如何通过语言服务器让 Copilot CLI 获得更真实的代码智能。语言服务器可以提供符号、定义、引用和诊断等上下文，让命令行 Agent 更理解项目结构。

Coding Agent 的战场正在从编辑器扩展到终端。只要 CLI 能拿到 IDE 级上下文，它就更容易进入自动修复、重构和项目巡检流程。

终端工具一旦接上语言服务器，就不再只是会聊天的命令行。编程 Agent 要进入真实项目，必须先拿到项目结构，而语言服务器正是这层基础设施。

  • 技术路径：通过安装和配置 LSP 服务器，把定义、引用、诊断等代码上下文带进终端
  • 战场扩展：Coding Agent 从编辑器扩展到终端
  • 基础设施：语言服务器是编程 Agent 进入真实项目的结构理解层
