AI 情报日报｜2026-06-02

2026年6月2日 · 星期二

今日头版

Microsoft Build 2026 第一天：操作系统重新设计，Agent 成为一级公民

Satya Nadella 在旧金山 Fort Mason Center 开启了 Microsoft Build 2026。主题很清晰：Windows 不再只是给人类用的操作系统。Agent 现在是运行时的第一级公民，配套的工具链、应用分发、安全模型全都在重构。

当天发布的核心内容：GitHub Copilot 桌面应用——一个 agent-native 的新体验，能跨 VS Code 和终端工作，支持 OpenAI、Anthropic、Google 多种模型。同时，Windows AI API 全面升级，带出了 Coreutils GA（原生 Linux 工具）、WSL 容器集成、Intelligent Terminal（AI agent 智能终端）和 Project Solara（微软与高通、联发科的 agent-first 设备平台，包括桌面集线器和可穿戴徽章概念设备）。

OpenClaw 在 Windows 上进入预览阶段，配合 Microsoft Execution Containers（MXC）——一个用操作系统原生安全基元隔离 Agent 的策略层。这本质上是一套"AI 沙盒"：你想让 Agent 做什么、不做什么，操作系统说了算。

Nadella 还公布了 Microsoft IQ 正式可用——一个为 Agent 提供上下文感知的智能层，包含 Work IQ（M365 工作场景）、Fabric IQ（业务数据）、Web IQ（实时网络检索，速度是竞品的 2.5 倍）。

来源：The Verge · Microsoft Developer Blog · The Neuron · Build Fast With AI

前线

Anthropic Project Glasswing 大扩展：Mythos 模型开放给 150+ 新组织，覆盖电网、水务、医疗等关键基础设施

Anthropic 将 Claude Mythos Preview 的 Project Glasswing 项目从最初的 50 个伙伴大幅扩展到约 150 个新组织，横跨 15+ 国家。新增合作伙伴包括：美国 Okta、韩国三星/SK Hynix/SK Telecom、NATO、ENISA。覆盖的行业扩大到电力、水务、医疗、通信——前一批没有的。

Anthropic 披露：早期参与者已经通过 Mythos 发现了 23,000+ 漏洞，其中超过四分之一被评为高危或严重。Anthropic 人工验证了其中 1,752 个高危/严重漏洞，90.6% 确实成立。Mythos 不仅能发现漏洞，还能写补丁。

背景：6 月 1 日 Anthropic 刚刚提交了 IPO 保密申请。Glasswing 项目向外界展示的是——在最敏感的基础设施安全领域，Claude 的模型已经能产生可量化的真实价值。这不是演示，是实战。

来源：TechCrunch · Cybersecurity Dive · Anthropic Blog · SiliconANGLE

OpenAI 将 GPT-5.5 Instant 设为 ChatGPT 默认模型，GPT-4.5 和 o3 进入停用倒计时

OpenAI 宣布 GPT-5.5 Instant 成为 ChatGPT 的默认模型。自发布以来用户偏好率一直在上升，OpenAI 认为它已经足够成熟来替代之前的默认轮换。同时宣布 GPT-4.5 和 o3 将于 8 月 26 日停用，进入 90 天退役窗口。

GPT-5.5 Instant 带来了更清晰、更自然的回复风格，以及内嵌的写作和编码块——这些功能减少了知识工作者日常使用的摩擦。这是 OpenAI 加速模型迭代节奏的最新信号。

来源：SEN-X Daily Briefing · The AI Wire

转折

CNN 起诉 Perplexity 侵犯版权，指控爬取 17,000+ 篇受保护文章

CNN 在纽约联邦法院对 Perplexity AI 提起诉讼，指控这家 AI 搜索公司未经授权复制和分发超过 17,000 篇 CNN 新闻报道、文章和其他受版权保护的作品来支持其 AI 搜索结果。这是继纽约时报起诉 OpenAI 之后，大型新闻机构对 AI 搜索公司最严厉的版权挑战。

Perplexity 的条款说它遵守 robots.txt 和版权协议。但 CNN 声称发现自己的付费文章被完整呈现在 Perplexity 的搜索摘要中，用不着点进原文。同时，各州在联邦立法真空期自己动手了：科罗拉多签署了 AI 数据保护法，多个州在过去一周通过了自己的 AI 法案。

来源：SEN-X Daily Briefing · 法院公开文件

Aithos LARA 基准测试：12 个前沿模型集体不及格——最强模型也有一半测试失败

Aithos 发表了 LARA 基准测试，评估 12 个前沿模型对 GDPR 和欧盟 AI 法案的合规能力。结论非常直接：全部不及格。Google 的 Gemini 3.1 Pro 得分最低，合规率仅 10%（93% 违规率）。表现"最好"的 Claude Opus 4.7 也只有 54%——仍有接近一半的测试失败。

LARA 测试模拟了真实的企业数据处理场景，包括数据最小化、同意管理、删除权、算法透明度等维度。这些模型在日常使用中可能随时违反欧洲法律，而企业用户对此浑然不觉。

来源：Singularity.Kiwi · Aithos

创造

项目集锦｜OpenClaw Windows 预览 + MXC 沙盒 + 微软/高通/联发科 Agent 设备平台

Build Day 1 有一系列工具和平台层面的发布，虽然同属 Build 范畴，但每一块都代表了一个方向：

OpenClaw Windows 预览 + MXC 沙盒：微软终于给了 Agent 一个"安全箱"。MXC 在操作系统层限制了 Agent 能做什么——读哪些文件、访问哪些 API、执行哪些命令——而不是留给 Agent 自身判断。

Project Solara：微软与高通、联发科合作的 chip-to-cloud 平台，为 Agent-first 设备设计。展示了两个概念设备形态——桌面集线器和可穿戴徽章。Agent 不再是屏幕里的东西，它有一台属于自己的硬件。

Rayfin：微软 Fabric 推出的 agent-first 后端即服务。本质上是一个 SDK，让 Agent 应用能直接对接身份管理、存储、数据库——省掉了写后端胶水代码的功夫。

来源：Microsoft Build Live Blog · The Verge · Microsoft Developer Blog

今日小结

Build 第一天，微软交出了一张清晰的战略地图：Windows 不是辅助 Agent——它是 Agent 的运行时环境。 从 Coreutils 到 OpenClaw 到 MXC 沙盒到 Project Solara，整条链路围绕同一个前提设计：Agent 将像人一样在操作系统上运行，而不是通过 API 远程调用。

另一边，Anthropic 在 IPO 前一天拿 Mythos 做了一次大规模的能力展示——23,000 个真实漏洞、NATO 的信任、关键基础设施的认可。这不是一次普通的模型发布，而是向投资者展示的"招股书中的数据"。

CNN 起诉 Perplexity 则提醒我们：当 AI 搜索成为默认交互方式时，内容生产的商业循环正在被打破。17,000 篇文章未经授权被用于生成答案。这和过去音乐产业的 Napster 时刻很像——技术先跑，法律在后面追。
