AI 情报日报｜6月3日

6月3日 · 星期三

今日头版

Microsoft Build 第二天：推出首个推理模型 MAI-Thinking-1——终于有自己的引擎了

Microsoft Build 大会第二天，微软 AI CEO Mustafa Suleyman 正式发布 MAI-Thinking-1，微软第一个自研推理模型。350 亿活跃参数、1 万亿总参数、256K 上下文窗口。微软自己的盲测：用户偏好与 Claude Sonnet 4.6 持平。

关键背景：微软过去两年所有的 AI 产品——Copilot、GitHub、Azure——基本都跑在 OpenAI 的模型上。MAI-Thinking-1 是微软第一次有自己的推理模型可以拿出来跟前沿对手放在同一个赛道上比。同时发布的还有 MAI-Code-1-Flash（专门给 GitHub Copilot 的编码模型，5B 活跃参数）和七款覆盖图像、语音、转录的其他模型。

Suleyman 同时公布了成本数据：针对咨询公司 McKinsey 调优后，MAI 模型在质量上超过 GPT-5.5，成本效率据称是 OpenAI 的 10 倍。微软官方的表述是"自建模型在 Azure 上跑，省掉了付给第三方的推理费用"。

跟你的关系：微软从"买模型的"变成了"造模型的"。不是放弃 OpenAI——是两边都做。但对开发者来说，Azure 上很快会有第三个（微软 + OpenAI + 开源）可选的推理引擎。

前线

微软 Majorana 2 量子芯片：可靠性提升 1000 倍——距离可用量子计算机还有三年

Nadella 在 Build 主题演讲中公布了 Majorana 2，微软第二代量子处理器。如果说 Majorana 1 证明了"基础物理可行"，Majorana 2 是"开始工程化"。Nadella 给出的时间线：2029 年实现可扩展量子计算机。

可靠性提升 1000 倍——指标来自微软内部测试。同时发布的还有 Aion 1.0 系列：两个小型模型（14B 参数），专门为 Windows 设备本地运行 AI Agent 设计，已在预览中。

Build Fast With AI · A Guide to Cloud

OpenAI 模型和 Codex 在 AWS 上全面可用——Azure 不再是唯一通道

OpenAI 的 GPT-5.5、GPT-5.4 和 Codex 在 Amazon Bedrock 上从受限预览转为 正式可用（GA）。这意味着任何 AWS 客户都可以通过 Bedrock 控制台直接调用 OpenAI 前沿模型，不需要单独的 OpenAI 账户或 Azure 订阅。

定价与 OpenAI 官方一致，无额外费用，使用量计入 AWS 既有云支出承诺。Codex 的周活用户已突破 500 万——比 4 月预览时的 400 万再增 100 万。OpenAI 同时预告，Daybreak 网络安全计划将是下一个登陆 AWS 的能力。

背景：4 月 27 日微软与 OpenAI 改合同结束了 Azure 独占条款，第二天 OpenAI 就和 AWS 宣布了合作。6 月 1 日 GA，6 月 3 日媒体集中报道。从改合同到全面可用，刚好五周。

OpenAI · Memeburn · A Guide to Cloud

转折

Sam Altman 在 Stargate 数据中心现场访谈：代码模型是目前最大的需求驱动力

CNBC 在密歇根州 Saline 的 Stargate 数据中心现场采访了 Sam Altman。Stargate 是 OpenAI 正在建设的大型 AI 基础设施项目之一，光这个站点开发和建设就花了 160 亿美元，内部硬件还要再投 300 亿。

Altman 最坦诚的一段话："代码模型是单一最大的需求驱动力。它们在去年底到今年初变得非常好，最近几个月又跨了一大步。" 他同时坦言自己低估了模型的"参差性"（jaggedness）——有些事做得极好，但长期复杂任务的监督能力还很弱。他也提到一个值得注意的现象：AI 用得最多的公司，也是招人最多的公司。

Oracle CEO 也在现场说了同样的话："当下的需求比我们能交付的还要多。"

CNBC · Smart Content Report

GPT-5.5 在 Microsoft Foundry 上正式可用

同一天，OpenAI 的 GPT-5.5 在 Microsoft Foundry 上正式可用（GA），包括 GPT-5.5 Pro 版本。定价：GPT-5.5 $5/百万输入 · $30/百万输出；Pro 版 $30/百万输入 · $180/百万输出。Azure Consumption Commitment 可抵扣。

微妙之处：同一天，OpenAI 的模型在 AWS 和 Azure 上同时 GA。之前的独占时代结束了，OpenAI 正式成为双云供应商。

A Guide to Cloud

创造

Microsoft 发布 Aion 1.0——能在 Windows 笔记本上本地运行 Agent 的小模型

Microsoft 发布了 Aion 1.0 系列，两个小模型（14B 参数）：Aion 1.0 Instruct 和 Aion 1.0 Plan。定位是为 Windows 设备提供本地 AI Agent 能力——不依赖云端，在笔记本上就能跑。

同时发布的 Microsoft Scout 是第一个"Autopilot"——一个永远在线的个人 Agent，能跨 Windows 和 Mac 运行，读取 Teams、Outlook、日历、OneDrive 和 SharePoint 来协调日程，发现工作流瓶颈并主动处理。你可以理解为一个用 OpenClaw 技术栈做的、永远在后台跑的 AI 助手。

今日小结

今天是 Build 大会日，观察 Microsoft 的战略很直观：模型、芯片、Agent 层，三层同时推进。

模型层出了 MAI-Thinking-1——微软第一个能跟 Sonnet 4.6 放在一起比的推理模型。芯片层出了 Majorana 2——1000 倍可靠性的量子进展，给出 2029 年的时间表。Agent 层出了 Aion 1.0（本地小模型）和 Microsoft Scout（永远在线的个人 Agent）。

另一边，OpenAI 在同一天实现了"双云 GA"——它的模型通过 Azure Foundry 和 AWS Bedrock 同时向企业客户开放。从独占到双云的转型，五周走完。

Sam Altman 在 Stargate 数据中心聊了一个值得记住的观察：AI 用得最多的公司，也是招人最多的公司。裁员的公司往往是对 AI 最保守的公司——这不是因果关系，但值得放在脑子里。
