09-01 · 算力基建 · 华为 / 昇腾 Atlas 950
华为首次展出 Atlas 950 SuperPoD，但真正的硬仗在万卡集群通信与软件生态

华为在 WAIC 世界人工智能大会现场正式展出 Atlas 950 SuperPoD 超级服务器集群。这是继今年初春公布架构规范后，物理机箱与高密拓扑互联结构首次面向公众完整曝光。

根据现场与行业分析机构披露的数据，该集群通过自研总线实现了超高密度的加速卡互联，重点解决大模型在万亿参数混合专家架构（MoE）下跨节点交换的带宽瓶颈。

硬件堆叠是可见的第一步，更关键的是算子库与长周期训练的可靠性：面对前沿实验室不断攀升的算力密度要求，国产集群能否支撑数月不中断的无损训练，是决定下一代基础模型研发节奏的核心门槛。

来源：SemiAnalysis

09-01 · 编程智能体 · Meta / Muse Code
Meta Muse Code 结束测试推可编程 SDK，命令行一条指令直接托管复杂重构，但真正的硬仗才刚刚开始

Meta 宣布其专门针对软件工程研发的 Muse Code 正式结束测试阶段，并推出全平台可编程 SDK。

开发者只需通过命令行一条指令即可将智能体集成进本地 IDE 与 CI/CD 流水线，支持在无人类频繁干预下自主跨模块检索调用、执行长程代码重构并提交带验证证据的补丁。

这标志着编码智能体从简单的代码补全向端到端全流程自治演进：工程师的角色正在从逐行码字者向系统架构审核人发生深刻转变。

来源：Meta Newsroom
09-01 · 商业机密 · Apple / OpenAI 诉讼
Apple 提交新取证指控前员工将电路数据带入 OpenAI，教智能体跑芯片仿真

Apple 在最新司法文件中提交了前工程师电脑的新证据，指控其离职时下载了机密电源转换器与高频电路图纸。

诉状进一步指出，相关数据涉嫌被用于在 OpenAI 内部指导自主智能体进行芯片与硬件电气系统的模拟仿真实验。

大模型研发的争夺已从纯语言文本蔓延至尖端硬件设计资产：顶尖科技巨头对底层物理设计与芯片架构机密的防御正在提升至最高诉讼级别。

来源：TechCrunch
09-01 · 具身硬件 · Hugging Face / Microduck
Thomas Wolf 展示 399 美元 具身机器人，桌面级硬件开发门槛被再次打穿

Hugging Face 联合创始人 Thomas Wolf 在社交平台公开展示了其自制双足具身机器人 Microduck 的机载运行仪表盘。

该硬件套件整体物料成本仅约 399 美元，内置轻量级边缘推理单元与基础传感器阵列，旨在为具身智能算法研究提供人人可负担的物理实验载体。

来源：Hugging Face 博客

09-01 · 开发者工具 · Anthropic / Claude Code
Claude Code 迎来关键补丁修复，终端长程自动化运行更加健壮

Anthropic 官方开源仓库发布了 Claude Code 最新维护版本，重点修复了 Bash 长程交互中的异常退出与环境状态持久化漏洞。

随着工程师在日常开发中越发依赖智能体在终端内直接执行编译、测试与 git 提交，命令行工具的稳定性和权限控制成为开发体验的关键决定因素。

来源：GitHub Release
09-01 · 基础研究 · Google Research / TimesFM-3
Google 推出 TimesFM-3 多变量时间序列基础模型，参数 330M 即插即用

Google Research 今日公布面向复杂工业预测的时间序列基础模型 TimesFM-3，仅以 330M 参数实现了高精度的多变量零样本预测。

该模型在能源电网调度、金融高频波动与智能运维日志监控等多样化场景中展现出优异的跨领域泛化能力。

来源：Google Research 官方博客
