VoxCPM：用 Tokenizer-Free 架构做多语言语音生成

清华 OpenBMB 团队把 TTS 模型的 tokenizer 层拆了。

VoxCPM 2 用 Tokenizer-Free 架构跳过了传统 TTS 模型的离散化步骤——直接处理原始音频 token，避免 tokenizer 引入的信息损失。在多语言 TTS、语音克隆、创意声音设计三个场景都开源了权重。

  • Tokenizer-Free 架构，跳过离散化
  • 支持多语言 TTS / 语音克隆 / 创意声音设计
  • 权重开源，可本地部署

来源：OpenBMB · github.com/OpenBMB/VoxCPM

创造·AI视频·产品转折·前线感

zvec：阿里巴巴开源进程内向量数据库，零外部依赖

C++ 写的向量搜索库，跑在进程内，不依赖 Milvus 或 Pinecone。

zvec 用 C++ 实现进程内向量索引，不走网络 I/O，延迟比独立向量数据库低一个数量级。适合 RAG 应用中不需要分布式部署的轻量场景——嵌入应用即可用，不用运维向量数据库集群。

  • C++ 进程内运行，零网络 I/O
  • 适合轻量 RAG / 语义搜索，不需运维集群
  • 开源可嵌入

来源：阿里巴巴 · github.com/alibaba/zvec

联邦法院命令 OpenAI 保留所有 ChatGPT 日志，包括用户已删除的对话

你删掉的对话，法院说不准删。

纽约联邦法官 Ona Wang 下令 OpenAI 无限期保留所有 ChatGPT 输出日志——包括用户主动删除的对话、"临时对话"和 API 调用记录。起因是 NYT 等新闻机构担心侵权用户会删除对话痕迹。OpenAI 称该命令"前所未有"，迫使公司违背自身隐私承诺，数亿用户的敏感数据面临泄露风险。

  • 法官 Wang 5 月 13 日下达保全令，覆盖 ChatGPT Free / PLUS / Pro 及 API 全部日志
  • OpenAI 称该命令迫使其违反与用户的隐私协议和全球隐私法规
  • 用户在 LinkedIn / X 上恐慌，网络安全专家称其为"不可接受的安全风险"
